# Contact Manager

A simple Contact Manager project built using Python.

## Features

* Add Contact
* View Contact
* Search Contact
* Update Contact
* Delete Contact
* Exit

## Technologies Used

* Python

## How to Run

Run the following command:

```bash
python contact_manager.py
```

## Project Description

This project allows users to manage contacts using a simple menu-driven Python program. Users can add, view, search, update, and delete contact information.
